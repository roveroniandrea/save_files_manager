# Known bugs & limitations

Format: ID · description · repro · workaround · status. Keep this file up to date (see `CLAUDE.md`).

| ID | Description | Repro | Workaround | Status |
|---|---|---|---|---|
| KB-001 | Steam Cloud may re-download the cloud copy and overwrite a swapped-in profile (or upload another profile's saves over the cloud copy). | Enable Steam Cloud for a game, switch profile, launch the game. | Disable Steam Cloud for that game (Properties → General → Steam Cloud). The app shows a warning when cloud sync is detected. | Open (by design, v1) |
| KB-002 | Games that store saves in the Windows registry are not supported. | Add a game whose saves live under `HKCU\...`. | None. | Open (not planned for v1) |
| KB-003 | Games that store saves inside their install directory may have them reset by Steam "Verify integrity of game files". | Verify files after switching profile. | Switch back to the profile after verifying; the profile copy is kept by the app. | Open |
| KB-004 | Changing the storage folder does not move existing profile data, so it is refused while any game is configured. | Settings → change storage folder with games present. | Remove all games first, or move the `games\` folder manually and edit `storage_root` in `config.json`. | Open (planned) |
| KB-005 | The swap unit is a whole folder: games that keep save files loose in a folder that also holds other files (e.g. directly in the game's install or exe folder) cannot be managed. Such folders are refused by the save path safety checks. | Add a game whose save path is its install folder. | None yet (file-level save paths could be added later). | Open (limitation) |
| KB-006 | Save folders containing symbolic links or junctions are not supported. | Put a junction inside a save folder and switch profile. | Remove the link. The switch fails safely during the backup step, before anything is modified. | Open (limitation) |
| KB-007 | Backups can only be restored for the profile that is currently active. | Try to restore a backup taken while another profile was active. | Switch to that profile first, then restore. | Open (by design, v1) |
| KB-008 | Save folders were stored as absolute paths (no placeholders), so they broke if the Windows user folder or drive letter changed. | Add a game, rename the Windows user / move the drive. | — | Fixed (templates; relocated at startup when the old folder is gone and the new one exists) |
| KB-010 | Steam Cloud detection is a heuristic (cloud data present in `userdata`, per-app/global `CloudEnabled` flags): it can warn for a game whose cloud sync was turned off in a way the app does not read, or miss one that has never synced on this PC. | Turn cloud off for a game in Steam and open it in the app. | Ignore the banner if you know cloud sync is off. | Open (heuristic) |
| KB-011 | Steam's cached library icon is only 32×32, so Steam game icons look blurry at larger sizes; it is missing if Steam has not cached it yet. | Add a Steam game. | Edit the game and choose the executable's icon or a custom image. | Open |
| KB-012 | Save folders of Steam games were not suggested; they had to be added by hand. | Add a Steam game. | — | Fixed (Ludusavi suggestions) |
| KB-013 | Suggestions follow the Ludusavi manifest, which can be wrong, incomplete, or list a folder that also holds non-save files; `<storeUserId>` is a wildcard, so all Steam accounts' folders are suggested. The automatic match is by Steam appid or exact name (ignoring case and punctuation); otherwise only fuzzy "Did you mean" names are offered, which can miss a game listed under a very different name (e.g. an abbreviation or a translated title). | Add a game the manifest does not know, or one with an unusual name. | Check suggestions before adding; use "Search the database" in the editor to pick the right entry, or add folders by hand. | Open (manual search added in milestone 10) |
| KB-014 | Suggestions are not checked against the folders already in the editor's list (nesting/overlap) until the game is saved. | Add a folder by hand, then a suggestion inside it. | Saving shows the error; remove one of them. | Open |
| KB-015 | Running detection misses games whose process runs outside the install folder (Steam games started through an external launcher installed elsewhere) or manual games without an exe / started through a different exe (launcher); a switch is then not blocked. | Start such a game and switch profile. | Close the game before switching. Set the real game exe for manual games. | Open (limitation) |
| KB-016 | Cloning the active profile, editing a game and other non-swap operations are not blocked while the game runs; a clone may capture half-written saves. | Clone the active profile while the game is saving. | Clone with the game closed. | Open |
| KB-017 | Technical details from the backend stay in English in the Italian UI: the "Details" text of error toasts, the reason a suggested folder cannot be used, the database download error in Settings, and the detail of a failed recovery. The main messages are translated (by error `kind`). | Switch the language to Italiano and trigger an error, or look at an unusable suggestion. | None needed; the summary line is translated. | Open (by design for v1) |
| KB-018 | The installer asks for its language only on the first install: the choice is stored in `HKCU\Software\Andrea Roveroni\Save Files Manager` → `Installer Language` and later installs/updates reuse it silently (standard NSIS `MUI_LANGDLL_DISPLAY` behavior in Tauri's template). The app's own UI language is a separate setting. | Install once, then run a newer installer. | Uninstall first (clears the value), or `reg delete "HKCU\Software\Andrea Roveroni\Save Files Manager" /v "Installer Language" /f`. | Open (by design) |
| KB-019 | The installer and the app are not Authenticode code-signed, so Windows SmartScreen (and some antivirus tools) may warn about an unknown publisher when the downloaded installer is run. Update integrity is still verified by the updater's own signature. | Download the installer from a GitHub release and run it. | SmartScreen: More info → Run anyway. | Open (no code-signing certificate) |
| KB-020 | Copies built or installed before the first release that contains the updater (milestone 12; any 0.1.0 build) cannot update themselves. | Run a 0.1.0 build after a newer release is published. | Download and run the newer installer from the GitHub releases page once; later versions update in the app. | Open (by design) |
| KB-021 | While the GitHub repository is private (or offline), the update check fails: `latest.json` cannot be downloaded without authentication. The startup check only logs the error; **Settings → Check for updates** shows an `update` error toast. | Settings → Check for updates while the repo is private. | Make the repository public (planned, see `docs/PROGRESS.md`). | Open (until the repo is public) |
| KB-022 | A started update download cannot be cancelled, and the update dialog stays open (Escape disabled) until it finishes or fails. | Install an update on a slow connection. | Wait, or close the app (nothing is installed until the download completed and was verified). | Open (minor) |
| KB-009 | Stored copies of a save folder removed from a game stay inside every profile until the profile (or game) is deleted, using disk space. | Edit a game, remove a save folder. | Delete unused profiles, or remove the `data\<save-path-id>` folder by hand. | Open (cleanup UI planned) |
